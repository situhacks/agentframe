# Project-management domain pack

The default domain: consulting, PM, and general work. Declaring `domain: project-mgmt` gives a project the neutral [`skeleton.md`](skeleton.md), the generic deliverable shape, and the `sources/` + `knowledge/` substrate ([`knowledge-base.md`](../../process/knowledge-base.md)). It adds no frontmatter fields, templates, or hooks.
