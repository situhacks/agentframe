# Harvests (schema)

Copy this note to `library/context/operator/career/harvests/README.md`.

Raw career material that arrives from somewhere else and has not been distilled yet: a
cross-instance export from the work AgentFrame, a performance-review PDF, a rubric an employer
sent, a screenshot of a live profile.

**This folder is a staging area, not a layer.** Nothing here is cited. `career-harvest` reads it
once and distils it into the layers that are cited — `proof-points.md` for the number,
`master-cv.md` for the bullet, `stories/` for the arc, `employers/` for standing. When an item
has been distilled, say so on its row and stop reading it.

| File | What it is | Arrived | Distilled |
|---|---|---|---|
| FILL-ME | e.g. work-instance career export zip | YYYY-MM-DD | no / YYYY-MM-DD |

Name files `YYYY-MM-DD-{what}.{ext}` so the folder sorts by arrival.

Instances are gitignored; only this shape is tracked.
